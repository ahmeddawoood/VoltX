# VoltX ⚡

I'm building VoltX as a project around EV charging and energy infrastructure.

The main idea is pretty simple: build a system that can manage EVs, charging stations, chargers, and charging sessions, and then see how far we can take it from there.

As the project grows, I'll be working with things like IoT, cloud, edge computing, real-time communication, energy management, and distributed systems.

## What I'm working on

- EVs and charging stations
- Chargers and charging sessions
- Reservations
- Real-time communication with chargers
- Energy management
- IoT and edge computing
- Cloud infrastructure

## Tech

- Java
- Spring Boot
- PostgreSQL
- Redis
- Kafka
- MQTT
- Docker
- React
- TypeScript

## Status

🚧 Still building it.

I'm starting with the basics and adding things as I learn and find interesting problems to solve.

## Why VoltX?

I wanted one project where I could put different software engineering concepts together instead of building lots of small demo projects.
